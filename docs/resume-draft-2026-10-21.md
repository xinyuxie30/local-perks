## 项目经历

### 智惠生活通 LocalPerks｜本地生活服务与优惠券交易平台

**项目时间：**［自行填写］　**项目角色：**［按实际填写］

**项目简介：** 面向本地生活场景，提供商铺查询、探店互动与优惠券秒杀，支持从领券下单到模拟支付、核销、取消及退款的订单流程，重点处理库存扣减、重复下单和缓存访问问题。

**技术栈：** Java、Spring Boot、MyBatis-Plus、MySQL、Redis、Redisson、RocketMQ、Caffeine、Nginx。

- **秒杀库存与异步下单：** 基于 Redis + Lua 原子完成库存校验、一人一单判断及库存预扣，结合 RocketMQ 事务消息和 Redis 事务标记支持 Broker 回查，将订单落库移至消费端处理，缩短入口同步处理链路。
- **消费幂等与订单流转：** 结合 Redisson 用户级锁、订单主键和用户—优惠券唯一索引处理重复消息，数据库扣库存与建单置于同一事务；通过订单状态条件更新处理支付与关单竞争，使用延迟消息关闭超时订单并回补库存。
- **多级缓存与访问保护：** 使用 Caffeine 与 Redis 构建商铺详情两级缓存，本地命中时不访问 Redis；结合布隆过滤器和空值缓存拦截无效查询，更新事务提交后删除缓存，通过 Pub/Sub 通知本地缓存失效并以 TTL 兜底。
- **接口限流与故障处理：** 基于 AOP、SpEL 和 Redis ZSET + Lua 封装滑动窗口限流，支持用户、IP 和全局维度；超限返回 429 及重试时间，支持限流组件异常时按配置放行或拒绝。
- **库存核对与维护保护：** 以订单记录为依据核对 Redis、MySQL 库存并补关超时订单；库存差异默认记录告警，受控修复采用 Redis CAS 和数据库条件更新；预热前校验历史订单、库存占用及快照，降低误重置风险。

### EchoMind｜本地生活业务智能助手

**项目时间：**［自行填写］　**项目角色：**［按实际填写］

**项目简介：** 为 LocalPerks 提供自然语言业务入口，支持商铺与优惠券检索、订单查询及经用户确认后的业务操作，将大模型工具调用与已有业务接口连接。

**技术栈：** Java、Spring Boot、Spring AI、DeepSeek、Redis、SSE。

- **Agent 执行与工具治理：** 实现“模型选择工具—参数校验—执行—结果回填”的多轮循环，对接商铺、优惠券和订单工具；设置轮次与总耗时预算，结合重复调用检测和异常结果回填，约束无效循环与工具调用行为。
- **业务写操作人工审批：** 将抢券、模拟支付、取消等操作接入逐调用确认流程，结合用户、会话及工具调用标识校验审批归属，通过 Redis Lua 原子认领审批令牌，拦截重复确认；使用 SSE 推送文本与工具事件，并在前端展示审批卡片。
- **上下文与知识管理：** 按预算组织对话历史，超限时进行摘要压缩；长期记忆按用户隔离，技能采用索引常驻、正文按需加载；平台规则问答结合 BM25 与字符 n-gram 哈希相似度进行轻量知识检索。
- **只读任务委派：** 将导购、内容推荐和订单检索拆分为三个只读子 Agent，通过工具白名单、独立上下文及执行预算限制任务范围，仅返回摘要；涉及业务写入的操作保留在主 Agent 审批流程。
